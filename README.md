# VSA-LAB4 — Hash Tables

## Məqsəd

C++ dilində həş cədvəllərinin qurulması, kolliziyaların
həlli və yük faktorunun performansa təsirinin ölçülməsi.

## Tapşırıqlar

1. Separate Chaining və MAD Compression
2. Open Addressing və Lazy Deletion
3. Empirik performans və kolliziya analizi

## Layihənin strukturu
